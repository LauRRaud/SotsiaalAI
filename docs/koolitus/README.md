ESTA kaardistab liikmete koolitusvajadust (küsitlus, tähtaeg **10.08.2026**, projektijuht
Liis Koppel) ja plaanib välja töötada tasulise 8-tunnise koolituse (hinnauuring 70–400 €).
Küsitluse teemavalikutes EI OLE ühtegi digi-/AI-teemat — see tühik on meie võimalus.
Lauri positsioon: ristumiskoht, kus seisab Eestis vähe inimesi (sotsiaaltöö sisu + AI
praktikas ehitatud + andmekaitse päris otsustena + regulatsiooni tundmine).

## Põhimõtted (lukus, ei pehmendata)

1. **Tööriista-agnostiline** — põhimõtted kehtivad ChatGPT-le, Copilotile, Geminile ja
   igale tulevasele tööriistale. SotsiaalAI-d EI demota.
2. **Huvide konflikt deklareeritakse esimesel slaidil** — „ma ehitan ise sellist tööriista;
   see on mu kogemuse allikas, mitte tänane müügiobjekt."
3. **AI on mustand, inimene otsustab** — koolituse punane niit, igas moodulis.
4. **Kõik faktiväited on allikaga** — AI-määrus, STAR-i strateegia, kvaliteedijuhis on
   tsiteeritavad (kontrollitud 28.07.2026, viited: `docs/platvormi arendus/sugiskool-2026-kusimustik.md` ptk 9).
